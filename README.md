Pedra, Papel e Tesoura em C#

Projeto simples desenvolvido em C# para praticar lógica de programação e relembrar conceitos básicos da linguagem.

SOBRE O PROJETO

O programa simula uma partida de Pedra, Papel e Tesoura entre o jogador e o computador.
O jogador escolhe uma das opções disponíveis e o computador realiza uma escolha aleatória. Em seguida, o programa compara as duas escolhas e informa o resultado da rodada.
Ao final, o jogador pode escolher se deseja jogar novamente.

*FUNCIONALIDADES*
- Escolha entre Pedra, Papel ou Tesoura
- Escolha aleatória do computador
- Exibição da escolha do jogador e do computador
- Identificação de empate, vitória ou derrota
- Opção de jogar novamente
  
*CONCEITOS PRATICADOS*
Durante o desenvolvimento deste projeto foram utilizados conceitos como:
- Console.WriteLine() e Console.ReadLine()
- Variáveis int e string
- int.Parse()
- Random
- switch
- if, else if e else
- Operadores ==, && e ||
- Estrutura de repetição do...while
  
*COMO EXECUTAR*
É necessário ter o .NET SDK instalado.
Clone o repositório:
git clone URL_DO_REPOSITORIO
Entre na pasta do projeto:
cd pedra-papel-tesoura-csharp
Execute:
dotnet run
